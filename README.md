# Can Machines Think Like Us?

### The Ability of Large Language Models to Pass Verbal Analogical Reasoning in Aptitude Tests

A collaborative graduation research project that investigates the ability of Large Language Models (LLMs) to solve verbal analogy questions in both **English and Arabic**, with a focus on evaluating and improving their analogical reasoning capabilities.

The project explores multiple approaches, including **Prompt Engineering, Chain-of-Thought prompting, fine-tuning experiments, and relational learning**, to better understand the strengths and limitations of LLMs in verbal analogical reasoning.

---

## 🎯 Research Objectives

- Analyze the performance of Large Language Models on verbal analogy questions.
- Evaluate reasoning performance across Arabic and English datasets.
- Explore different prompt engineering strategies.
- Investigate Chain-of-Thought prompting for analogical reasoning.
- Explore fine-tuning approaches using relational datasets.
- Investigate relational representation approaches using RelBERT.
- Collect and curate Arabic verbal analogy questions.
- Develop an educational tool for practicing verbal analogies.

## 🔍 Key Findings

The experiments highlighted that the effectiveness of prompting strategies depends on the model.

- More detailed Chain-of-Thought prompting improved the reasoning performance of GPT-3.5.
- Longer and more detailed prompts did not consistently improve GPT-4o and could reduce its performance.
- Combining relational representations with an LLM was explored as a hybrid approach for handling different types of verbal analogies.
- The experiments demonstrated differences in reasoning behavior across models, languages, datasets, and prompting strategies.

## 🌐 Lubb — Educational Application

As an applied outcome of the research, we developed **Lubb**, an interactive bilingual educational website designed to help students practice verbal analogical reasoning.

Lubb includes:

- An AI-powered verbal analogy solver.
- Arabic and English support.
- Interactive analogy quizzes.
- Multiple difficulty levels.
- Timed practice sessions.
